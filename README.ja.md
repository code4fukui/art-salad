# Art Salad

Art Saladは、没入型VR空間で、芸術作品や歴史的遺物の3Dスキャンから作られたジグソーパズルを遊べるウェブサイトです。

## 特徴
- VR（バーチャルリアリティ）でジグソーパズルをプレイ
- 芸術作品や歴史的遺物の3Dスキャンから作られたパズル
- 無料かつオープンソース

## 動作環境
Meta QuestなどのVRヘッドセットが必要です。

## 使い方
1. VRヘッドセットを装着します。
2. ウェブブラウザを起動します。
3. https://artsalad.net にアクセスします。
4. `enter VR` をクリックします。
5. パズルをお楽しみください！

## データ
ほとんどのパズルモデルは [Sketchfab](https://sketchfab.com/) から取得しており、Creative Commonsライセンスの下で提供されています。
